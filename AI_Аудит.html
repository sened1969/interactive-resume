Глоссарий основных понятий и аббревиатур

7
Термин / Аббревиатура Определение
МСА (ISA) Международные стандарты аудита – основа аудиторских процедур.
Rule engine (движок правил) Система применения экспертных логических правил к проводкам для выявления аномалий.
CatBoost Алгоритм градиентного бустинга от Яндекса, эффективен для табличных данных с категориальными признаками.
LSTM (Long Short-Term Memory) Тип рекуррентной нейронной сети для анализа временных рядов (дебиторка, авансы).
Монетарная выборка (MUS) Метод отбора элементов с вероятностью, пропорциональной сумме (МСА 530).
LLM (Large Language Model) Большая языковая модель (DeepSeek-V3.2, YandexGPT) для генерации текста, объяснений.
AI Search Инструмент Yandex AI Studio для поиска релевантных данных в интернете и корпоративных базах.
Code Interpreter Изолированная среда выполнения кода для вычислений, визуализации, конвертации.
SHAP Метод интерпретации предсказаний ML-моделей (важность признаков).
ОСВ Оборотно-сальдовая ведомость – агрегированный отчёт по счетам.
Пояснение: Понимание терминологии обеспечивает эффективное взаимодействие с платформой и точную интерпретацию результатов.
