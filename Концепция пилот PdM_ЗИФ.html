Слайд 3. Текущий процесс (реактивный)

Реактивный подход (80% ремонтов): MTBF 720ч, MTTR 48ч, OEE 85%

Проблемы: климат Мончегорска, ручной мониторинг, высокий риск пропуска сигналов.

Слайд 4. Предлагаемое решение

ML PdM: CatBoost (P(сбой) > 80%) + LSTM (RUL 48–168ч)

  • SCADA/IoT: вибрация до 10 Гц, ток 1 Гц, температура.
  • Feature engineering: RMS, kurtosis, FFT, rolling-статистика.
  • CatBoost — двоичная классификация вероятности сбоя.
  • LSTM — регрессия RUL для планирования ремонта.
  • Интеграция: IoT → SCADA → Kafka → ML-кластер КГМК → PLC + Power BI.

from catboost import CatBoostClassifier
from sklearn.model_selection import TimeSeriesSplit

model = CatBoostClassifier(
    iterations=1000,          # 1000 деревьев
    learning_rate=0.05,       # Консервативно для стабильности
    depth=6,                  # Баланс переобучения
    l2_leaf_reg=3,            # Регуляризация
    random_seed=42,
    # cat_features: тип оборудования, смена и т.п.
    early_stopping_rounds=50,
    verbose=100,
)

LSTM (регрессия RUL - Remaining Useful Life)

from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense, Dropout

model = Sequential([
    LSTM(64, return_sequences=True, input_shape=(30, 12)),  # 30 шагов, 12 фич
    Dropout(0.2),
    LSTM(32, return_sequences=False),
    Dropout(0.2),
    Dense(16, activation="relu"),
    Dense(1),  # RUL в часах
])

model.compile(
    optimizer="adam",
    loss="mae",  # Mean Absolute Error
)

Целевые метрики: AUC ROC > 0.90, MAE < 48ч, R² > 0.85.

Слайд 11. Основные термины и сокращения

PdM & Метрики

PdM
Predictive Maintenance (предиктивное обслуживание)
MTBF
Mean Time Between Failures (среднее время наработки на отказ)
MTTR
Mean Time To Repair (среднее время восстановления)
OEE
Overall Equipment Effectiveness (общая эффективность оборудования)
RUL
Remaining Useful Life (оставшийся ресурс)

ML & Данные

AUC ROC
Area Under ROC Curve (площадь под ROC-кривой)
MAE
Mean Absolute Error (средняя абсолютная ошибка)
RMS
Root Mean Square (среднеквадратическое значение)
Kurtosis
Куртозис (характеристика «хвостов» распределения)
FFT
Fast Fourier Transform (быстрое преобразование Фурье)

Инфраструктура

SCADA
Supervisory Control And Data Acquisition
Kafka
Apache Kafka (потоковая платформа)
ClickHouse
OLAP БД для больших данных

ROI = Return On Investment (окупаемость), TBM = Time-Based Maintenance (плановое обслуживание)
